# Reference

Historical documents. Kept because they record decisions, not because they
describe the site as it stands today. Where this folder and the code disagree,
the code is right.

| File | What it is |
| --- | --- |
| `web-build-plan.html` | The build plan written before the site existed — the page inventory, the URL structure and the content model that were agreed up front. Useful for understanding *why* the site is shaped the way it is. Open it in a browser. |
